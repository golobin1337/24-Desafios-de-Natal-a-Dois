IMAGENS ORIGINAIS (fonte)

Estas são as imagens originais. A página publicada NÃO usa esta pasta direto:
o comando "npm run otimizar" gera as versões otimizadas em assets/img/.

Para trocar uma imagem:
  1. Coloque o arquivo novo aqui (WebP, JPG ou PNG — qualquer tamanho; ele é convertido
     para WebP e reduzido automaticamente, sempre mantendo a proporção, sem distorcer).
  2. Se o nome mudou, atualize o src="images/..." correspondente em src/index.html
     (e/ou src/index-b.html).
  3. Rode: npm run otimizar

  download_3.webp                       Dobra 2 - calendário aberto (paisagem)

  f3688c8e..., fe1f2dbc..., 2d869069...      Dobra 3 - prints de depoimentos

Dica de qualidade: as páginas do livro ficam mais nítidas no celular com ~1000 px de largura.
